# Grant Ready Weekly — email template

Extracted verbatim (structure and standing copy) from the Sep 28, 2026 send
to Plain Truth Baptist Church (message id `1a0e834e115846a5`). Placeholders
in `{{...}}` are the only parts that change per client/week.

## Envelope

- **To:** `notary@delawaremobilesignings.com`
- **Cc:** each of the client's `contacts.cc` entries
- **Subject:** `Grant Ready Weekly — {{Mon DD, YYYY}} — {{org_name}}`

## Body

```
GRANT READY WEEKLY
Delaware Mobile Signings — Grant Readiness & SAM Registration Services

Hi {{org_name}} team,

{{one- or two-sentence opener — vary naturally week to week, e.g. noting
list length or a theme, as in past sends ("A shorter list than usual this
week — but a genuinely useful one.", "Here's what we found scanning this
week's grant and foundation opportunities.")}}

This Week's Matched Opportunities

{{for each matched opportunity (only include real search results — omit
this section's items entirely rather than inventing one):}}
{{Opportunity Title}}
Funder: {{funder name}}
Deadline: {{deadline or "Rolling / no fixed deadline"}}
{{one to two sentences on why it matches this client's criteria}}
View Opportunity → {{url}}

{{optional — include only when true, do not fabricate:}}
A note on {{other funding category}} funding this week
{{honest note when this week's search on that front didn't turn up a
strong match for this client's geography/org type — say so plainly and
suggest a concrete next step, as in: "This week's search on that front

... which wouldn't apply to a Delaware-based organization. Nothing strong

Resource of the Week
{{One practical, short grant-readiness tip. Not a link roundup — a single

Questions about any of these? Reply to this email or reach out to Marcia

This is a curated selection from public grant databases, not a guarantee of

```

## Notes for the weekly-send step

- Every "View Opportunity" link must come from an actual search result for
  that client's `criteria`. A short, honest list is correct; a padded list
  with invented opportunities is not.
- The funding-gap note is optional and only appears when a search category
  genuinely came up empty for that client's geography/org type — state that
  plainly rather than omitting the miss silently.
- The "Resource of the Week" should rotate — don't repeat the same tip two
  weeks running for the same client.
- Sign-off name/persona ("Marcia Boyer, Delaware Mobile Signings") and the
  closing disclaimer line are standing copy — reuse verbatim.
